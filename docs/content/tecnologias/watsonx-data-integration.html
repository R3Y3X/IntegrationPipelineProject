Qué es watsonx.data integration

Es la plataforma unificada de integración de datos de IBM: un plano de control SaaS que reúne capacidades antes dispersas en productos independientes bajo una experiencia común de diseño, despliegue y observabilidad.

No confundir con una sola herramienta

StreamSets es el motor de streaming visual dentro de la plataforma. También incluye DataStage (batch ETL/ELT), Data Replication (CDC), Databand (observabilidad) y UDI (datos no estructurados para AI).

El portfolio dentro de la plataforma

Cada capacidad resuelve un estilo de integración distinto. La plataforma los expone desde el mismo plano de control, con conexiones y gobernanza compartidas:

IBM DataStage

Batch ETL / ELT

Cargas programadas de alto rendimiento hacia warehouses y lakehouses. Transformaciones complejas sobre datos estructurados con paralelismo masivo.

  • ETL y ELT para volúmenes batch
  • Asistente genAI (Granite) para generar pipelines desde lenguaje natural
  • Disponible como servicio en IBM Cloud y AWS

IBM StreamSets

Streaming en tiempo real

Pipelines visuales de datos en movimiento: consumir, transformar, enriquecer y publicar eventos con latencia de segundos.

  • Canvas Origin → Processors → Destinations
  • Preview por stage y manejo de data drift
  • Engines en cloud, híbrido o Kubernetes

IBM Data Replication

CDC / Replicación

Captura y entrega incremental de cambios desde sistemas operacionales (Oracle, DB2, etc.) hacia destinos analíticos.

  • Sincronización de baja latencia sin full reloads
  • Oracle CDC, XStream y conectores enterprise
  • Mantiene aplicaciones y analítica alineadas

Unstructured Data Integration

Documentos y AI

Ingesta y preparación de PDFs, presentaciones y texto para analytics y workflows de AI/RAG.

  • Operadores: PII masking, quality filter, language detection
  • Canvas visual + Python SDK
  • Integración con frameworks de orquestación AI

IBM Databand

Observabilidad

Capa transversal de monitoreo: salud de pipelines, alertas, root cause y detección de anomalías en entregas de datos.

  • Visibilidad unificada sobre batch, streaming y CDC
  • Detección temprana de fallos y degradación
  • Reduce tiempo de remediación manual

StreamSets dentro de la plataforma

StreamSets es la capacidad de streaming visual de wxDI — una pieza del portfolio, no la plataforma completa. Su modelo de pipeline conecta orígenes, procesadores y destinos en un canvas ejecutable:

  • Preview por stage: inspeccionar registros en cada punto sin publicar a destino.
  • Data drift: stages que detectan y adaptan cambios de schema en origen.
  • Conectividad amplia: Kafka, JDBC, S3, HTTP, Confluent Schema Registry y más.
  • Bifurcaciones: un processor puede alimentar múltiples destinos (ej. Kafka + JDBC).

Relación con DataStage y Replication

Usá StreamSets cuando el dato debe procesarse en movimiento. Usá DataStage para cargas batch masivas. Usá Data Replication cuando necesitás sincronizar cambios incrementales sin transformación compleja.

Casos de uso

Modernización analítica

Migrar datos desde mainframe, SAP u OLTP hacia lakehouses con batch (DataStage) y CDC (Replication).

Decisiones en tiempo real

Procesar eventos de Kafka u otras fuentes con StreamSets para scoring, enriquecimiento o alertas.

Datos listos para AI

Preparar documentos y contenido no estructurado con UDI: masking, filtrado de calidad, chunking para RAG.

Operación confiable

Monitorear todos los estilos de integración con Databand: alertas, root cause y SLA de entrega de datos.
