Protege las credenciales

No copies API keys o secrets en capturas, chats ni archivos del repositorio. Esta guía utiliza placeholders de forma intencional.

Criterios de éxito

  • Pipeline_N consume, clasifica y publica sin errores.
  • Nombre, correo y tarjeta aparecen enmascarados en la salida.
  • Confluent decodifica los mensajes como Avro, sin encabezados Obj.
  • El agente consulta únicamente TransaccionesEvaluadas-N.
