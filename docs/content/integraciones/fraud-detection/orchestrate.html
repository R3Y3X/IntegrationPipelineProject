Importación de N{N}_fraud_analyst

Descarga tu YAML, importa tu agente y consulta los resultados enmascarados de TransaccionesEvaluadas-N. El toolkit MCP es compartido para todos. Las credenciales te llegarán por correo.

Contexto activo

Selecciona tu número en Inicio antes de copiar configuraciones.

Objetivo

Preparado por IBM

Toolkit remoto workshop_fraud_mcp (MCP en la VM del workshop), agent-spec-N.yaml para descargar desde Inicio y credenciales enviadas por correo.

Tu tarea

Activar la CLI e importar N{N}_fraud_analyst. Tu agente usa el toolkit compartido y siempre pasa topic_number="{N}" → TransaccionesEvaluadas-N.

Prerequisito

Pipeline_N debe estar en ejecución y publicando mensajes Avro válidos. Si el tópico está vacío, el agente no tendrá datos que analizar.

Cómo encaja todo

El MCP corre en la VM del workshop. Orchestrate se conecta a él mediante el toolkit workshop_fraud_mcp. Tu agente elige el tópico con topic_number en cada llamada.

CapaNombreQué hace¿Quién lo prepara?
MCP (servidor) VM workshop :8101/sse Lee Kafka/Schema Registry. Recibe topic_number en cada tool. IBM (uno para todos)
Toolkit workshop_fraud_mcp Registro remoto en Orchestrate. Expone las cuatro tools MCP. IBM (una sola vez)
Agente N{N}_fraud_analyst Siempre llama las tools con topic_number="{N}". Tú (importas desde el YAML)
Credenciales Orchestrate API Key Autentica tu sesión de CLI frente a la instancia TechZone. IBM (enviadas por correo)

Flujo al hacer una pregunta

Chat → N{N}_fraud_analyst → get_fraud_summary(topic_number="N") → toolkit workshop_fraud_mcp → MCP en la VM → TransaccionesEvaluadas-N.

Bloque 0 — Obtener tu YAML

  1. Confirma tu número N en Inicio y selecciónalo en el selector.
  2. Descarga agent-spec-N.yaml desde la sección de descarga de Inicio.
  3. Localiza el correo de IBM con tus credenciales — necesitarás la Orchestrate API Key en el paso de activación.

Solo el YAML — sin ZIP

El archivo descargado es únicamente la spec del agente. Las credenciales y la URL de la instancia te llegan por correo. No hay nada que descomprimir.

No importes toolkit

El toolkit workshop_fraud_mcp ya está registrado en Orchestrate por IBM. Tu YAML solo referencia sus tools.

Bloque 1 — Preparar la CLI

Paso 1 — Ambiente virtual

Abre una terminal en la carpeta donde descargaste el YAML:

python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install ibm-watsonx-orchestrate
orchestrate --version

En Windows PowerShell, activa el ambiente con .venv\Scripts\Activate.ps1. Confirma con orchestrate --version — debe mostrar la versión sin errores.

Paso 2 — Activar instancia TechZone

Usa la Orchestrate API Key y la URL que IBM te envió por correo.

orchestrate env add \
  --name workshop \
  --url https://api.ca-tor.watson-orchestrate.cloud.ibm.com/instances/c3385561-1fc9-40d5-a072-01acb6137494

orchestrate env activate workshop \
  --api-key <Orchestrate API Key>

Si el ambiente workshop ya existe, ejecuta únicamente env activate.

No guardes el secreto

No pegues la API key en el YAML del agente, el repositorio ni una captura.

Bloque 2 — Importar tu agente

Resumen del bloque

  1. Confirma que workshop_fraud_mcp aparece en orchestrate toolkits list (IBM lo registró antes del lab).
  2. Importa agent-spec-N.yaml.
  3. Tu agente fija topic_number="{N}" en cada llamada.

Paso 3 — Verificar toolkit compartido

orchestrate toolkits list

Debe aparecer workshop_fraud_mcp con las tools get_fraud_summary, get_suspicious_transactions, get_transaction_detail y get_customer_activity. Si no está, avisa al facilitador.

Paso 4 — Importar agente

orchestrate agents import --file agent-spec-N.yaml
orchestrate agents list

Confirma que aparece N{N}_fraud_analyst con las cuatro tools de workshop_fraud_mcp.

Tools del agente
ToolUso
get_fraud_summaryConteos, montos y top riesgo (topic_number fijado por el agente).
get_suspicious_transactionsLista alertas ordenadas por score.
get_transaction_detailInvestiga una transacción específica.
get_customer_activityResume la actividad reciente de un cliente.

Bloque 3 — Probar en UI

Paso 5 — Activar el agente

  1. Abre la instancia de watsonx Orchestrate en el navegador.
  2. Busca N{N}_fraud_analyst.
  3. Comprueba que las cuatro tools de workshop_fraud_mcp estén asociadas.
  4. Activa o despliega el agente y abre su chat de prueba.

Paso 6 — Consultas de prueba

Ejecuta estas preguntas en orden. Haz clic para copiar:

Resumen

"Dame un resumen de las transacciones evaluadas y los casos de mayor riesgo."

Alertas

"Muéstrame las transacciones sospechosas y fraudulentas ordenadas por score."

Explicación

"Explícame por qué la transacción con mayor riesgo fue clasificada de esa forma."

Cliente

"Resume la actividad reciente del cliente con más alertas."

Paso 7 — Validar aislamiento y masking

  • El diagnóstico indica TransaccionesEvaluadas-N.
  • El agente no permite solicitar otro número de tópico.
  • El nombre del cliente no aparece en claro.
  • El correo conserva solo la parte permitida por la máscara.
  • La tarjeta muestra únicamente los últimos cuatro caracteres.

Si aparece PII en claro

No la repitas ni la copies. Detén la prueba y revisa Field Masker en Pipeline_N antes de continuar.
